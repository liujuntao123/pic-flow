# 长图内容质量标准

长图的完成条件是读者能顺着动线读懂、记住，并相信它。每个项目在写 layout 前先完成以下检查。

## 事实与表达

- 把每条关键断言分成三类：有来源的事实、基于事实的解释、为了叙事而创作的漫画化表达。
- 事实数字必须注明口径；“号称”“约”“至少”等限定词不能省略。
- 文学作品、传说和影视桥段不能伪装成史实。直接引语要有出处；没有可靠出处的对白改写成“漫画化台词”或旁白。
- 不用一个漂亮但过度精确的数字概括复杂过程。无法确认时使用时间范围、阶段性结论或明确说明不确定性。
- 每块只保留一个核心判断；正文解释“为什么”，插图展示“发生了什么”，两者必须相互对应。

## 阅读动线

- 首屏在 3 秒内回答“这张图讲什么，以及为什么值得继续看”。
- 呼吸感是信息设计的一部分：每个 block 只保留一个主视觉、一个核心判断和最多一个辅助解释；气泡、标签、装饰线不能与核心判断争夺同一级注意力。
- 画布至少保留约 15% 的有效留白，并在主视觉与正文之间留下可见间隔；连续两个 block 都是高密度时，下一块必须安排一个低密度转场或大场景。
- 高潮块可以密集，但高潮前后要降密度。不要为了填满画布增加重复形容词、第二个结论或无信息气泡。
- 每块包含路标、核心判断和解释；核心判断可以脱离正文单独读懂。
- 相邻块至少改变一种阅读动作：图左文右、文左图右、满幅场景、时间线、对比或大字重锤。
- 55%～70% 位置放冲突或关键转折，最后一块完成结论回收，而不是重复标题。
- 删除只制造气氛、没有推进信息的句子；幽默必须服务理解或节奏。

## 交付前人工验收

1. 不看插图只读文字，能复述主题、因果链和结论。
2. 不看正文只看插图，能说出每张图表现的动作；看不出来就换 prompt 或换构图。
3. 标出所有数字、引语和判断，逐项核对来源、口径和语气。
4. 以 550px 预览快速扫读：标题层级、块间节奏、视线方向和收束是否成立。
5. 随机从中段开始阅读，仍能知道当前章节位置和上下文。
