# pic-flow 设计方法：整图叙事与科普动线优先

本文是视觉系统（`style-guide.md`）与排版质检细则的**上游**，确立长图在分镜规划、视觉权重、AI 生图防御与版面呼吸感上的通用规则。默认面向叙事与解释型长图；具体主题、风格和信息结构应由项目需求与主题包决定。

## 核心命题

**长图的设计单位不是独立的 block，而是连贯沉浸的阅读动线。**
排版引擎执行的是逻辑与叙事的推进，而非生硬的信息容器。
逐块孤立合格 ≠ 整图视觉成立；整图动线与呼吸节奏成立，信息才能被高效吸收与记忆。

## 第一层：storyboard（分镜规划先行）

在编写具体排版代码前，必须先确立每个 block 的四元组，明确其全局定位：

| 字段 | 取值 | 核心职能 |
|---|---|---|
| `role` | hook / context / buildup / climax / consequence / meaning / ending | 该分块在全局叙事/论述推进中承担的角色 |
| `density` | low / medium / high | 读者在该节点承受的视觉与信息负荷 |
| `focal` | left / right / center / full_bleed | 视觉重心位置，与相邻块形成交替错落 |
| `notes` | 自由文本 | 视觉任务：读者在当前节点必须记住的核心事实或机制 |

全图动线检查四项指标：
1. **首屏钩子（Hook）**：第一块在 3 秒内抛出核心矛盾、悬念反差或宏大视野，给出不划走的理由。
2. **高潮定位（Climax）**：全篇张力或冲突峰值落在 55%~70% 进度处，杜绝平铺直叙。
3. **相邻差异（Rhythm）**：相邻两块的主体方位、图文结构、信息密度至少一项不同；全图连续居中构图 ≤2 块。
4. **终局收束（Closure）**：最后一块完成核心结论回收与深层洞见提炼，而非内容的机械衰减。

## 第二层：构图语法与视觉支配

- **主视觉焦点原则**：每个分块应有一个主要视觉焦点，并与本块信息直接对应。叙事块可展示关键动作，解释型内容可展示机制状态、关系结构、数据变化或关键对象。
- **视觉面积支配（Visual Dominance）**：叙事型黑白手绘项目可将视觉图形面积约 60% 作为默认基线；信息密集型项目按可读性、信息完整性和发布尺寸调整。
  全景/对抗大场景统一铺设至 980~1020px 满幅；核心主体立绘高度控制在 480~560px；
  正文严格精炼为 4~8 行的短促叙述，坚决杜绝长篇大论吞噬画面的文字教科书化倾向。
- **动线交替推进**：图文版式在块间有序交替（左图右文 ↔ 右图左文 ↔ 居中 ↔ 满幅出血），推动读者视线自然下滑，避免单调的垂直均速下坠。
- **关系优先与空间闭环**：每个元素必须具备明确的视觉归属。对白/陈述气泡必须在物理空间上精准对齐发话实体的实际坐标与朝向；解读文字紧密贴靠其解读对象；关键指标单独突出。
- **受控负空间与零遮挡导引**：气泡主体必须居于主体边缘之外的纯净负空间中（保留 ≥40px 缓冲），通过长 tail 完成视线牵引。**绝对禁止任何气泡底色或描边压盖主体的面容、关键标识或核心轮廓线**。

## 第三层：信息层级、动态留白与去容器化

- **三层信息递减结构**：节点标签（紧凑节奏）→ 核心判断（一句话结论）→ 解释性正文。三层齐全且视觉权重严格递减。
- **动态留白与呼吸感（Visual Breathing）**：高级感来自张弛有度的视觉呼吸，而非填满。
  段落与段落之间垂直留白保留 **80~140px**，正文与大场景/立绘之间保留 **120~200px** 空气流通带；
  图文水平并排时水平间隙保留 **80~120px**；文字下边缘与横向分割线（rule）保留 **≥60~100px** 缓冲，严禁文字挤压或跨线溢出。
+- **辅助信息先算包围盒（Supporting Information Placement）**：补充说明、要点、标签和短注属于独立的信息栏，必须先读取素材实际渲染尺寸与包围盒，再确定文字的 `x`、`y`、`max_width`。文字栏与主体墨迹至少保持 80px 水平净空；若窄栏导致要点拆成孤字或多余折行，应调整主体尺寸与位置、扩大栏宽或提高块高，不得把文字叠到主体插图上。
- **字号阶梯大字阶标准（Mobile Readability Scale）**：长图以移动端 550px 缩放阅读为基准，字号绝不能偏小。
  总标题 `52~60px`、节标题 `42~48px`、正文 `32~36px`（行距 1.45~1.5）、气泡字 `28~32px`（统一搭配 `#4A2800` 深棕字，避免多色杂乱）、尾块毛笔金句 `40~46px`。
- **去容器化画卷哲学（De-containerization）**：整张长图是**一卷连续的纸**——
  画面里任何元素都不该声明自己的边界。这条法则同时管住文字与图形两侧，缺一侧画卷就断：
  - **文字侧**：除结构性对照看板外，**严禁滥用带边框底色的矩形卡片（card）包裹正文或结论**。
    文字直排于通透底色上，依靠字体族切换与字号阶梯自然建立层级。
  - **图形侧**：**插图同样不许自带方框**。一张把画格填满、四周有平直收口线、底部横着一条
    贯穿地面线的插图，本质上就是**一张用墨画的 card**——它贴上去的一瞬间，画卷就断了。
    插图的墨迹必须在四边由密到疏自然消散，构图开放、不闭合。
  - 二者的共同判据是同一个：**这个元素有没有在画面上画出一条"我到此为止"的线**。
    文字用它当卡片边框，插图用它当背景墙与地面线。
- **画面边界消解（Edge Dissolution）**：插图的"贴纸感"不是画风问题，而是**构图指令问题**。
  凡是要求"主体居中、四周留白"的写法，模型必定产出自成一体的小方图；
  正确的写法是反过来的——**开放式构图**：背景全部留白、只画人与必要道具、
  **绝不画贯穿画面的地面线/地平线/地脚线**、画面四周墨迹由密到疏自然消散、
  允许某一侧稀疏到几乎没有。量化判据见 `check_edges.py` 的"硬边数"，全图素材应趋近 0。
- **自然叙事收束（Organic Narrative Closure）**：尾部分块严禁设置形式化的大框框标题，
  避免产生教条说教感；让核心洞见或哲理总结直接作为收尾视觉主角，自然流淌而出。
- **语义色彩语法**：严格沿用 style.json 预设的语义色（hl/quote/warn），全图主色相 ≤4，色彩温度跟随论述张力起伏，严禁使用装饰性杂色。

## 第四层：AI 素材生成的防御性工程（Prompt Defensive Patterns）

- **开放式构图与边界消解（Open Composition / Edge Dissolution）**：**每条 prompt 的第一约束**。
  插图是要"落"在白纸上的，不是要"贴"在白纸上的。写法上必须：
  ① 背景全部留白，只画人物与必不可少的少量道具，**绝不写"殿宇梁柱森然""帷帐低垂"这类包围式布景**
  ——写了模型就一定把画格填满；② 明令**不许画贯穿画面的地面线、地平线、地脚线、桌沿线**；
  ③ 要求四周墨迹**由密到疏自然消散**，边缘只剩零星线头，不许出现连续的平直收口线与矩形边界；
  ④ 允许构图开放、不闭合，某一侧稀疏到几乎没有也行，四边不必都有内容。
  > 反直觉但已被实测证实：**"主体居中放置、四周留出充足留白"是贴纸感的元凶**。
- **跨分块主体锚点锁定（Anchor-Locking）**：同一核心实体/角色在不同分块出现时，
  Prompt 必须前置固定三项辨识锚点（轮廓体态 + 核心识别标识 + 专属代表色/配饰/符号）。
  发生状态剧烈转变时，约束为"在保留基础特征前提下的外化神态反差"，杜绝模型自由发挥导致辨识体系崩塌。
  **落地机制**：锚点写进 `sheets.json` 的 `anchors`，用 `{角色名}` 占位符在**每个格子逐字展开**
  ——跨格形象一致靠的就是这种一字不差的重复，而不是靠提示词里的形容词。
- **专业实体具象化与反向排除（Concrete Domain Entities & Negative Constraints）**：严禁使用易引发模型跨时空、跨文化或跨领域错置的抽象隐喻；必须明确指定符合该题材领域的具象实体（如特定专业器皿、仪式器具、专业图表、经典文献模型），并显式追加反向排除从句（*“绝对禁止出现任何与题材背景相违和的现代生活杂物或跨领域道具”*）。
- **高潮场景动势与墨重强化（Momentum & Ink-Weight）**：高潮大场景必须强制注入粗黑钢笔墨线、纯黑墨块对比与强动势氛围，排斥浅淡灰线与平淡呆板表情，确保关键冲突或突破节点的视觉张力拉满。
- **纯物态特写的无躯体净化（Pure Object Isolation）**：概念/道具特写必须声明为纯物态构图，显式要求*“严禁出现无关的完整人物身躯”*，防止横向空间被庞大形体撑满挤死文字排版通风口。

## 第五层：机器检查链与双代理对抗闭环质检（Machine Gates + Dual-Agent Review）

素材侧与排版侧各有一组机检，**全绿才进人工/代理审查**：

| 侧 | 脚本 | 判据 |
|---|---|---|
| 素材 | `check_edges.py` | **硬边数**（四边外侧窄带墨迹覆盖率 >0.65 的边数）趋近 0；边缘墨迹占比越低越好 → 没有方图感 |
| 素材 | `make_transparent.py` | 透明通道与四向紧致裁边正常 |
| 排版 | `layout_lint.py` | 碰撞、越界、居中滥用，**hard 必须 = 0** |
| 排版 | `check_geom.py` | 真实字体度量下的自动折行、行宽越界、孤字行；插图带高 ≥55% |
| 排版 | `check_occlusion.py` / `check_clearance.py` | 气泡与素材墨迹**压盖 0 px**；气泡底缘与主体轮廓净空 ≥40px |

1. **机检前置**：上表全绿，通过后方可进入视觉审查。
2. **双代理对抗审查**：生成代理专注于排版与生图，独立评审代理以严苛总监视角进行全景质检：
   - 逐像素排查气泡底色/描边是否覆盖主体重要轮廓线条；
   - 审查**插图有没有方图感**（四周是否出现平直收口线、是否画了包围式布景与贯穿地面线）；
   - 审查主体特征是否跨块漂移、道具是否领域错置、高潮是否张力不足；
   - 执行**中心压缩打分（1-10分制，7.0~8.5 为健康工业基准）**，存在硬性遮挡一票否决；
3. **定点修正闭环**：按审查清单下发精准坐标修改量或针对性重构素材，复检直至获得【PERFECT PASS】终审裁决。
4. **全景缩放扫读确认**：通过 550px 缩略图确认移动端视线流动、文字可读性与呼吸感。

## 通用反面模式清单（Universal Anti-patterns）

- **卡片囚笼**：滥用 card 框格包裹正文，撕裂画卷整体感
- **方图贴纸**：插图自带平直收口线、把画格填满，像贴纸一样"贴"在白纸上而非"落"在白纸上
  （成因几乎总是提示词写了"主体居中、四周留白"或"殿宇梁柱森然"这类包围式布景）
- **贯穿地面线**：哪怕是人物立绘，只要脚底横着一条贯穿画面的地平线/地脚线，底部立刻变成一条硬边
- **文字压倒画面**：视觉面积 <60%，排版冗长如教材
- **穿刺与重叠遮挡**：气泡边框压盖主体轮廓或关键结构线
- **声源空间错位**：气泡 tail 与发话实体的实际空间朝向倒置
- **主体形象漂移**：前后分块核心角色/实体的识别符号不一致
- **违和道具错置**：特定专业或时代场景出现跨领域/跨时空的异质元素
- **标签式说教**：收束生硬打上形式化框框标题
- **元素孤岛与相册排版**：主体与文字零空间呼应，所有正文机械同宽居中
- **把版式交给生图模型**：让模型自己排分镜格、画黑框、写画面内文字，
  产出必然滑向"漫画页"而非"图文结合长图"——**版式与文字归排版引擎，模型只负责画插画**
