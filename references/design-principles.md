# pic-flow 设计方法：整图叙事优先

本文是 `style-guide.md`（视觉系统）与「构图多样性 checklist」（逐块细则）的**上游**：
回答"排版之前必须先决定什么"。所有规则保持抽象——具体做什么动作、用什么意象，
一律由当前项目的内容推导，skill 不预设任何主题的特化约束。

## 核心命题

**长图的设计单位不是 block，是阅读动线。**
排版引擎执行的是叙事，不是内容的容器。逐块合格 ≠ 整图成立；
反过来，整图动线成立时，单块的局部瑕疵也更容易被阅读惯性原谅。

## 第一层：storyboard（写 layout 之前必须存在）

每个 block 先填四元组，回答不出来就先改内容，而不是改坐标：

| 字段 | 取值 | 回答的问题 |
|---|---|---|
| `role` | hook / context / buildup / climax / consequence / meaning / ending | 这块在叙事里承担什么职能 |
| `density` | low / medium / high | 读者这一眼的信息负荷 |
| `focal` | left / right / center / full_bleed | 视觉重心在哪，与相邻块是否错开 |
| `notes` | 自由文本 | 视觉任务：读者这一眼**记住什么** |

全图层面检查四件事：

1. **钩子**：第一块 3 秒内给出不划走的理由（悬念、反差、大数字、大场面）。
2. **高潮位置**：全图张力峰值落在 55%~70% 进度处，而不是均匀分布。
3. **相邻差异**：相邻两块的主角方位、图文方向、密度至少一项不同；全图连续居中构图 ≤2 块。
4. **收束**：最后一块是记忆点（金句/结论/回环），不是内容的自然衰减。

## 第二层：构图语法（正向规则）

- **主视觉动作**：每个叙事块有且只有一个主视觉，且它在"做"一件与内容匹配的事。
  动作从内容推导——故事块来自人物的关键行为，教程块来自操作的关键瞬间，
  数据块来自趋势的异动点，对比块来自差异的最大处。主视觉"静止"的块只允许出现在钩子与收束。
- **方向性**：图文阅读方向在块间交替（图左文右 ↔ 文左图右 ↔ 居中 ↔ 满幅出血），
  让视线被推动而不是匀速下坠。斜向构图与出血是张力来源，留着给高潮块用。
- **关系优先于摆放**：逐元素检查"它和谁有关系"。对话气泡必须指向说话者；
  解读文字贴着它解读的对象；关键数字/引语作为视觉锚点单独放大。
  两个元素只有坐标相邻而没有语义关系，即返工。
- **叠压是深度线索**：允许并鼓励元素间 15~80px 的受控叠压（文字压图形边缘、
  前景压背景），零叠压的版式会退化为相册。

## 第三层：信息与色彩

- **三层信息结构**：章节标签（小而有节奏）→ 动作/结论（本块的一句话）→ 解释正文。
  每块三层齐全，但视觉权重递减；只有一层信息的块是标题图，两层的是 PPT。
- **密度分层而非留白**：高级感来自层次清晰，不来自空白。留白必须服务于强调或转场，
  否则补内容。这类长图的表达力主要来自密度。
- **颜色是语法**：严格沿用 style.json 的语义色（hl/quote/warn 及其扩展），
  全图色相 ≤4，颜色温度跟随叙事张力（铺垫冷、高潮暖），禁止装饰性用色。

## 第四层：连续性系统

块与块之间用**一种**贯穿机制缝合，全图只用一种：

- 进度提示行（每块底部的下一块预告）；
- 章节编号系统（统一的编号徽章 + 章节色）；
- 贯穿视觉元素（同一条线/同一组角色/同一底纹跨块延续）。

混用两种以上机制等于没有机制。首块建立的视觉契约（字体、色温、动线方向），
尾块要有意识地回应。

## 质检门（顺序固定）

1. **机检**（`layout_lint.py`）：碰撞、越界、旋转包围盒、居中滥用。
   机器通过的 block 才进入识图环节。
2. **识图审查**（`--debug` 渲染 + read_image）：查关系（气泡指向、解读贴靠、
   断行质量）与节奏（本块与前后块是否形成差异）——这两类机器测不了。
3. **正式渲染终验**：确认真实墨迹下的最终效果。

## 反面模式（在原 checklist 基础上新增）

- 元素孤岛：人物/图表独立站桩，与文字零关系
- 等高均分：所有块同构同高，节奏死亡
- 装饰性留白：用空白冒充高级感
- 卡片网格化：万物皆圆角卡片，块内块外一个样
- 颜色当装修：高亮色失去语义，读者无法靠颜色导航

## 规则的抽象性声明

本文件中的每条规则都以"由当前项目内容推导"为前提。
skill 的 examples/ 目录存放具体项目的成品与过程稿，它们是规则的**证据**，
不是规则本身；把某个项目的具体动作、措辞、意象写成本文件约束，即为过拟合，禁止。
