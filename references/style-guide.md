# pic-flow 设计系统

## 定位

《半小时漫画》（混子曰）式历史科普长图：黑白 Q 版手绘线稿 + 现代口语吐槽 +
少量彩色强调。整体"素色底 + 局部跳色"，彩色的唯一来源是文字系统与气泡，
因此彩色必须**语义化**，不能当装饰乱用。

## 文字高亮语义

| 标记 | 渲染 | 语义 | 例 |
|---|---|---|---|
| `【…】` | 橙 + Medium | 专名/计策/概念/关键动作 | 【草船借箭】【放行】 |
| `『…』` | 蓝 + Medium | 原话、引语、反讽引用 | 『再言降者，如同此案』『含恨』 |
| `〖…〗` | 红 + 毛笔 +8% | 伤亡、数字、结局性强信息 | 〖八十万大军〗就此崩盘 |

原则：一段最多 1~2 处高亮；高亮是"划重点"不是"涂鸦"。

## 气泡/标签形态语义（box.style）

| style | 视觉 | 什么情绪/内容用 |
|---|---|---|
| `fill` | 橙圆角 | 默认对话，百搭 |
| `outline` | 白底黑描边 | 慌乱、次要角色、旁白吐槽 |
| `sketch` | 双线随手框 | 淡定、运筹帷幄的角色 |
| `burst` | 爆炸星形 | 暴怒、呐喊、打脸台词 |
| `ink` | 墨底白字 | 狠话、决绝、悲壮 |
| `pill` | 胶囊 | 短促口语、状态词 |
| `stamp` | 红印章（无底） | 标签："某某计达成"、"flag 立住" |
| `marker` | 荧光笔划线 | 旁白提问、总结横幅（非对话） |

- `tail`（bl/bc/br/tl/tc/tr）指向说话人；对话气泡优先加。
- 全图禁止两个气泡完全同款（形态或角度至少差一样）。
- `rotate` ±3~6° 歪贴；高度错开，不要一字排开。

## 构图模式库（每 block 挑 1~2 个模式）

1. **主从对照**：大主角(高 500~620) + 小配角(300~420)，基线错开 80~200px
2. **对峙/追逐**：左右两角色朝向相对，中间留 50~150px 交叠区，小者在前
3. **出血场景**：场景 width 1080~1160 满宽；或角色 x 越出画布边被裁切
4. **文字绕图**：左对齐窄栏(max_width 560~620) + 小图(h 330~430)占另一侧
5. **探头**：角色大半在画布内，边缘留 10~40px 似"从旁边探进来"
6. **压帽檐**：气泡底部与角色头顶重叠 20~80px，像从头上冒出来
7. **大字重锤**：高潮块标题 84~96px；封面主标题 150~170px
8. **标签点缀**：纯高亮文字 rotate ±3° 当状态标注（"反间计达成"）

反面模式（出现即返工）：左右对称等大双图；所有气泡同款同角度；
所有正文同宽居中；素材与文字零交叠的"相册式"排版；标题字号全图统一。

## 排版几何

- 画布统一宽 1080；块高 1400~1600（重点块 1900~2400）；总高 ≈ 13000。
- 顶部标题基线 y=90；正文段落间距 ≥60；素材与文字垂直间隙 ≥30。
- 气泡 pad [20,28] 会向四周外扩——排完必须过一遍 --debug 碰撞检查。
- 元素按数组顺序层叠：场景/大图先画，人物次之，气泡标签最后。
- 换行引擎已处理避头点（，。！？等不落行首）与 ASCII 词不拆分；主动断行用 `\n`。
