# pic-flow 设计系统

## 定位

黑白手绘风格叙事与科普长图：以纯白底色与粗黑 Q 版手绘线稿为骨架，融合生动叙事口吻与轻度语义强调色。
整体呈现"素色底 + 局部跳色"，彩色的唯一来源是文字系统与气泡，因此彩色必须**语义化**，绝不作无意义装饰。
适用于历史风云、人物博弈、科学原理、商业案例复盘及重大事件深度科普。

## 文字高亮语义

| 标记 | 渲染 | 核心语义与排版职能 |
|---|---|---|
| `【…】` | 橙 + Medium | 专有名词、核心实体、关键机制或决定性动作 |
| `『…』` | 蓝 + Medium | 原始引语、观点表述、现场原声或修辞提问 |
| `〖…〗` | 红 + 毛笔 +8% | 核心量化指标、决定性转折点或全局性最终结论 |

原则：一段最多 1~2 处高亮；高亮是"划重点"不是"涂鸦"。

## 气泡/标签形态语义（box.style）

| style | 视觉特征 | 适用情绪与语义场景 |
|---|---|---|
| `fill` | 橙底深棕字，圆角 | 默认陈述与日常对话，平易近人 |
| `outline` | 白底黑描边，黑字 | 被动方回应、客观陈述、内心旁白吐槽 |
| `sketch` | 双线随手框，黑字 | 冷静自信、运筹帷幄、主动谋划或权威宣告 |
| `burst` | 爆炸多角星形，橙底 | 激烈情绪、突发冲突、强力反驳或惊叹反应 |
| `ink` | 墨黑底白字，方角 | 决绝决断、终局宣告、威慑性定论 |
| `pill` | 胶囊形小标签 | 紧凑词条、状态反馈、短促确认 |
| `stamp` | 红印章双框（无底） | 节点标记：关键目标达成、突发异动或结论确证 |
| `marker` | 荧光笔划线横幅 | 章节转换引导、全局性问题抛出（非角色台词） |

- `tail`（bl/bc/br/tl/tc/tr）精准指向当前发话实体的视觉焦点，严禁悬空或反向。
- 全图禁止两个相邻气泡完全同款（形态或旋转角度必须形成差异）。
- `rotate` ±2~5° 错落排布；高度与重心错开，避免机械水平排开。

## 构图模式库（每 block 挑 1~2 个模式）

1. **主从对照**：主要实体(高 500~620) + 次要实体(300~420)，基线错开 80~200px
2. **对峙/碰撞**：左右两实体朝向相对，中间留 50~150px 交叠区，小者在前
3. **出血场景**：场景 width 1000~1080 满宽铺设，视觉面积充分舒展
4. **文字绕图**：左对齐窄栏(max_width 520~600) + 特写图(h 380~460)占另一侧，水平间距 ≥60px
5. **探头**：视觉元素大半在画布内，边缘留 10~40px 似"从边缘探入"
6. **对角错落与负空间牵引**：气泡置于实体斜上方或侧方留白处，通过长 tail 指向实体，气泡底缘与实体边缘保持 40~80px 纯净负空间，绝对禁止任何底色块压盖实体轮廓
7. **大字重锤**：高潮块标题 84~96px；封面主标题 150~170px
8. **标签点缀**：纯高亮文字 rotate ±3° 作为关键节点标记

反面模式（出现即返工）：
- **卡片囚笼**：滥用带边框或底色的矩形卡片（card）包裹正文或金句，撕裂整体画卷；除结构性对照外，文字一律直排底色；
- **文字压倒画面**：图片面积占比 <60%，文字冗长密不透风，长图退化为图文教材；
- **重叠与穿刺遮挡**：气泡边框、底色或文字压盖主体头部、轮廓线或核心结构线；
- **声源空间错位**：气泡放置位置与发话实体的实际空间朝向倒置；
- **相册式冷漠排版**：所有正文同宽居中、左右对称等大双图、所有气泡同款同角度。

## 排版几何与安全边界

- 画布统一宽 1080；块高根据内容张弛浮动于 1600~2200（避免机械等高均分）；全图总高 ≈ 10000~15000。
- **视觉面积支配**：插图与视觉图形面积占比必须 ≥60%；正文严格精炼为 4~8 行短促叙事，把空间留给画面与呼吸。
- **绝对零遮挡红线**：气泡边框及文字与主体轮廓之间必须保留 ≥40px 的安全通风口；尾巴（tail）负责完成视线索引，气泡主体必须居于纯净负空间中。
- **左右分栏通风口**：左右图文并排时，素材边缘与文本起始边之间，水平间隙必须 ≥60~90px，严禁贴脸拥挤。
- **基线与顶线呼应**：并排说明文字顶部 y 坐标应与立绘顶部处于同一水平视线（误差 ≤20px），防止上方空旷断层。
- **分割线防穿透**：段落文字下边缘与横向分割线（rule）之间保留 ≥50~80px 缓冲，严禁文字行穿越分割线。
- 换行引擎已处理避头点（，。！？等不落行首）与 ASCII 词不拆分；主动断行用 `\n`。

## 质检清单（机检与对抗审查逐项过）

- [ ] 零遮挡红线：气泡（含矩形底、描边、文字）与任何插图核心墨迹无任何像素级覆盖与穿刺
- [ ] 视觉面积：插图占比 ≥60%，大场景满幅（≥980px），主要立绘高度足量（≥480px）
- [ ] 声源闭环：所有对话气泡 tail 方向与发话实体在画面中的空间物理坐标完全对齐
- [ ] 去卡片化：无冗余的矩形背景 card，文字直融白底，由字阶自然成层
- [ ] 留白与呼吸：正文与横线留白 ≥50px，图文水平间隙 ≥60px，无文字溢出或上下断层
- [ ] 移动端扫读：550px 缩放全景下标题、对白气泡与高亮结论清晰顺畅，无孤字拆词
