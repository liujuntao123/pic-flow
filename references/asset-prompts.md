# 素材 Prompt 工程指南

## 统一风格后缀

`style.json` 中的 `asset_suffix` 会自动追加在每条 prompt 后（以默认 `bw-sketch` 为例）：

> 。风格：黑白幽默历史漫画，粗黑钢笔线条勾边，Q版夸张比例，简洁白色填充，
> 少量灰色排线阴影，类似《半小时漫画》的画风。纯白色背景，无投影，
> 画面中绝对不要出现任何文字、字幕、对话框、边框、水印。

编写 prompt 时只需专注于**主体构图与动作描述**，无需在每条中重复声明全局风格词。

## 通用主体描述公式

```
[时代/阵营身份] + [Q版人物/场景] + [标志性辨识锚点：头饰/服饰/兵刃/毛发] + [单一关键行为瞬间] + [外化冲突情绪]
```

- **单一动作瞬间**：一张图只演一场核心戏；动作必须单一、定格在关键爆发瞬间（如"挥戈斩断案几"、"闪电探手抢夺信物"），杜绝"正在讨论"等静态模糊描述。
- **符号化身份锚点**：画面无任何说明文字，全靠视觉符号辨认身份（文臣谋士的长袍卷轴、统帅主将的重甲佩剑、市侩贪婪者的局促身段与死抱钱袋）。
- **情绪高度外化**：得意狞笑 / 怒发冲冠 / 贼眉鼠眼 / 满头冷汗目瞪口呆。
- **大场景给足动势环境**：横向场面写明"横向满铺构图"，给足环境动势（硝烟、狂风、战旗、飞扬尘土）。

## 防御性 Prompt 四大铁律（Universal Defensive Rules）

1. **跨分块角色锚点锁定（Anchor-Locking）**：
   在多块中出场的核心人物，必须前置声明固定特征三元组（脸型 + 标志性毛发细节 + 专属头饰/服装）。情绪失控时，约束为"在保留基础容貌前提下的夸张颜艺反差"，严禁让模型自由发挥导致变脸崩盘。
2. **时代道具时空具象化与反向排除（Anachronism Prevention）**：
   严禁使用易触发模型现代常识的抽象隐喻（如用现代概念隐喻多方利益分配或对决）。必须严格指定贴合题材时空背景的具象实体道具（如特定时代礼器、器皿、卷轴文书或古制博弈工具），并显式追加排除句：*“绝对禁止出现任何现代违和物品、现代生活用品或西洋道具”*。
3. **高潮场景动势与墨重强化（Momentum & Ink-Weight）**：
   Climax 大场景必须强制注入粗黑钢笔墨线、纯黑墨块对比、战旗猎猎与冲锋杀伐氛围，显式排斥浅淡灰线与呆板笑脸，防止冲突高潮退化为平淡低幼早教卡通。
4. **纯物态概念特写的无躯体净化（Pure Object Isolation）**：
   算盘、天平、印章、令牌等概念特写必须声明为纯物态构图，显式要求*“严禁画出完整人体躯干”*，防止横向空间被庞大人物撑满挤死文字安全通风口。

## 6 类通用长图视觉素材规范

| 素材类型 | 推荐尺寸 | 核心任务 | Prompt 规范要点 |
|---|---|---|---|
| **1. 封面/开篇大场面** | `1792x1024` | 3秒抓住读者眼球，确立时空背景与核心矛盾 | 横向满铺构图，宏大阵营对立或地平线全景，给足环境动势 |
| **2. 主角核心动作立绘** | `1024x1024` | 展现主策划者或核心推动人物的主动行为 | 前置锁定人设锚点，做局/发力定格动作，神情冷峻或狡黠 |
| **3. 次要角色/对抗立绘** | `1024x1024` | 形成情绪反差，承载打脸、受骗或崩溃对白 | 夸张体态，滑稽守财、惊惶失措或颜艺反差，肢体语言饱满 |
| **4. 纯物态概念特写** | `1024x1024` | 视觉化抽象的谋略、数字、规则或利益博弈 | 飞速动作残影，锁链/砝码/器物特写，声明无完整躯体 |
| **5. 冲突决战高潮大图** | `1792x1024` | 叙事张力峰值爆发，决定性的命运转折 | 横向满幅，钢铁洪流/战车战马并辔冲锋，强墨线与杀伐动势 |
| **6. 尾声哲理收束立绘** | `1024x1024` | 提供宏大历史纵深与宿命感，承接全篇金句 | 背影或侧颜大步迈向开阔地平线，长袍迎风飘扬，意境悠远 |

*(注：具体题材的完整素材清单可直接参考官方标杆案例 `examples/jin-six-nobles/assets.json`)*

## 抽卡、返工与标准化

1. **单图冒烟测试**：先生成 1 张单人立绘测试风格与上游连通性，确认线条硬度与墨水对比符合预期后再批量跑 `gen_all.py`；
2. **定点缺陷返工**：
   - 出现面容漂移 ➔ 强化特征锚点词；
   - 出现现代物品穿帮 ➔ 具象化实体描述 + 增加负向排除词；
   - 构图横向占位过大 ➔ 补充“垂直紧凑构图，避免横向撑满”；
3. **标准化处理**：生成后统一运行 `python3 scripts/make_transparent.py assets/*.png`，确保透明通道与四向紧致裁边正常。
