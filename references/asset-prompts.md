# 素材生成指南：逐块四图 + 开放式构图

本文是素材生产的主线规范。核心只有两句：

1. **一个 block 一次生图出 4 张插画**（2×2 网格 → 切开 → 交给排版引擎）；
2. **每条 prompt 的第一约束是"开放式构图"**——插图要"落"在白纸上，不是"贴"在白纸上。

---

## 一、素材策略：两档，不是一档

| 档 | 何时用 | 规模 | 命令 |
|---|---|---|---|
| **逐块四图（默认）** | 立绘、道具、纯物态特写、不需要超过 ~700px 宽的中型场景 | 8 块 → **8 次生图 = 32 张插画** | `scripts/gen_sheets.py` |
| **单张全幅（补充）** | 需要 980~1080px 满铺的封面/高潮大场景 | 全图 2~3 张 | `scripts/gen_all.py`（读 `assets.json`） |

### 为什么默认走逐块四图

- **生图次数断崖下降**：逐张抽卡是 N 次，逐块四图是 N/4 次。
- **块内笔触天然统一**：同一张画稿、同一支"笔"，四张插画的线条粗细、排线密度、黑白比例不会有差异。
- **跨块不会漂移**：素材按块归属，不需要靠"全图共享池"去对齐不同 sheet 的画风。

### 为什么要给全幅场景留一档单张

上游**按总像素封顶（实测约 1.57 MP），等比缩放，只保留长宽比**。所以"把画布开大"换不来更多像素，
**画布长宽比才决定每格像素**：

| 排版 | 请求 → 实回 | 每格 | 每格像素 | 适用 |
|---|---|---|---|---|
| 1×1 | 1792×1024 → 1659×948 | — | 1.57 M | 满铺大场景、单张立绘 |
| 2×2 | 2048×2048 → 1254×1254 | 627² | 393 k | **立绘、道具**（默认） |
| 3×2 | 1792×1024 → 1659×948 | 553×474 | 262 k | 中型场景（6 格时用） |
| 3×3 | 2048×2048 → 1254² | 418² | 175 k | 小图标，慎用 |

**判定线**：某张素材在版面上要被放到 800px 宽以上 → 不要塞进网格，走单张。

## 二、网格 prompt 的三段结构

`gen_sheets.py` 自动拼装，你只写第 2 段：

```
① 表头（脚本固定）：画稿切分 + 开放式画法四条（见第三节）
② 单元格（你写）：第N格（方位）：{角色锚点} + 画面内容 + 否定项
③ 风格后缀（style.json 的 asset_suffix；spec 顶层可加 "suffix" 覆盖）
```

规格文件 `sheets.json` 写法：

```json
{
  "anchors": {
    "LEAD": "主角固定特征三元组：轮廓体态 + 标志性细节 + 专属符号",
    "NEG": "绝对禁止出现任何现代物品、现代服装、……、任何画面内文字与数字"
  },
  "sheets": [
    { "sheet": "sheetBlock1", "size": "2048x2048", "cols": 2, "rows": 2,
      "cells": [ { "name": "p1a_main", "prompt": "……{LEAD}……{NEG}" } ] }
  ]
}
```

```bash
python3 scripts/gen_sheets.py                      # 断点续跑
python3 scripts/gen_sheets.py --only sheetBlock1   # 只跑一块
python3 scripts/gen_sheets.py --force              # 强制重来
python3 scripts/gen_sheets.py --spec 别的规格.json  # 换规格文件
```

切分由 `slice_sheet.py` 自动完成：边界**吸附到最近的整条纯白行/列**（±90px 容差），
不硬切"宽÷列数"，所以模型轻微偏心也不会切到墨；某格内容贴到格子边界会判"疑似串格"并非零退出。
sheet 原图与 `*_slice_debug.png` 切割调试图都留在 `sheets/` 备查。

## 三、开放式构图四条（每条 prompt 的第一约束）

表头已固化这四条，**但单元格内容也必须配合**——你写的场景描述不能把它们推翻。

1. **背景全部留白**，只画人物与必不可少的少量道具。
   **绝对不要写"殿宇梁柱森然""帷帐低垂""朝堂内景""城墙延伸"这类包围式布景**——
   写了模型就一定把画格填满，产出一张方图。
2. **绝对不要画贯穿画面的地面线、地平线、地脚线、桌沿线**——人物的脚与器物直接落在空白上。
3. **四周墨迹由密到疏自然消散**：边缘只剩零星线头、排线渐稀、留白渐多；
   不许出现连续的平直收口线、矩形边界、整块背景填充。
4. **构图开放、不闭合**：某一侧稀疏到几乎没有也可以，四边不必都有内容。

> **反直觉但已实测**：旧版表头写的"每格内只画一个独立完整的主体，**主体居中放置、四周留出充足留白**"
> 正是贴纸感的元凶——它等于在教模型"画一张自成一体的小图"。要画卷感就得反着写。

**量化验收**：`python3 scripts/check_edges.py assets/*.png`
看两个数——**硬边数**（四边外侧窄带墨迹覆盖率 >0.65 的边数，0~4，越少越好，应趋近 0）
与**边缘墨迹占比**（越低说明墨越往中间聚）。

## 四、角色锚点：靠"逐字展开"，不靠形容词

跨格/跨块形象一致，**不是**靠提示词里写"保持一致""同一个人"，
而是靠 `anchors` 里的特征三元组**在每个格子被逐字展开**——模型看到的是同一段特征字符串。

```
[时代/阵营身份] + [轮廓体态：清瘦高挑／魁梧壮硕／体态丰腴] +
[标志性细节：蓄短须、鬓角两缕散发、束发戴低矮黑布冠] + [专属符号：腰间革带挂木质简牍袋]
```

- **单一动作瞬间**：一张图只演一场核心戏，动作必须单一、定格在关键爆发瞬间
  （"挥戈斩断案几""一把攥住对方手腕"），杜绝"正在讨论"这类静态模糊描述。
- **符号化身份锚点**：画面无任何说明文字，全靠视觉符号辨认身份。
- **情绪高度外化**：得意狞笑 / 怒发冲冠 / 满头冷汗目瞪口呆。
- 状态剧烈转变时，约束为"保留基础特征前提下的外化神态反差"，**不许省略基础特征**。

## 五、网格单元类型与写法

每个 block 建议固定四格：**主场景 + 主角立绘 + 对手/配角立绘 + 纯物态点题物**。
四格类型不同，版面上才有主从与节奏可排。

| 单元类型 | 核心任务 | Prompt 规范要点 |
|---|---|---|
| **主场景** | 承载该块的核心冲突瞬间 | 横向场面，写成"某人正在完成一个决定性动作 + 另一人做出被动反应"，一动一静成反差；人物以外全部留白 |
| **主角核心动作立绘** | 展现主策划者的主动行为 | 前置角色锚点，做局/发力定格动作，神情冷峻或狡黠；**脚下不画地面线** |
| **次要角色/对抗立绘** | 形成情绪反差，承载打脸、受骗或崩溃 | 夸张体态，滑稽守财、惊惶失措或颜艺反差，肢体语言饱满 |
| **纯物态点题物** | 把抽象的谋略/规则/数字落成实体 | 必须声明*"画面中不出现任何人体、手臂与面孔"*，防止横向空间被身躯撑满挤死文字通风口 |

需要满铺大场景时（另走单张 `assets.json`）：

| 单张类型 | 推荐尺寸 | 核心任务 |
|---|---|---|
| 封面/开篇大场面 | `1792x1024` | 3 秒抓住眼球，确立时空背景与核心矛盾 |
| 冲突决战高潮大图 | `1792x1024` | 叙事张力峰值，钢铁洪流/战阵冲锋，强墨线与杀伐动势 |
| 尾声收束立绘 | `1024x1024` | 宏大历史纵深与宿命感，背影或侧颜走向开阔地平线 |

*(注：完整素材清单可参考官方标杆案例 `examples/huangchao-tang-collapse/sheets.json` 与 `templates/sheets.json`)*

## 六、抽卡、返工与标准化

1. **单块冒烟测试**：先跑一块（`--only sheetBlock1`），确认线条硬度、墨色对比与上游连通性，
   再批量跑全部 sheet。
2. **标准化**：生成后统一 `python3 scripts/make_transparent.py assets/*.png`
   （透明通道 + 灰雾清理 + 四向紧致裁边）。
   ⚠️ 新切出来的素材**必须先跑这一步**：`check_clearance.py` 的墨迹蒙版用 alpha 通道，
   不转透明的话整张素材会被当成"全是墨"，净空检查全部失真。
3. **定点返工对照表**：

   | 症状 | 处方 |
   |---|---|
   | 插图像贴上去的方图（`check_edges` 硬边数高） | 删掉 prompt 里的包围式布景描写 + 补"不画贯穿地面的线、四周墨迹自然消散" |
   | 底部出现一条贯穿横线 | 明令"不画地面线/地脚线，人物与器物直接落在空白上" |
   | 面容漂移 | 强化 `anchors` 里的特征三元组，确认每个格子都用了 `{占位符}` |
   | 现代物品穿帮 | 具象化实体描述 + 加强 `NEG` 负向排除词 |
   | 横向占位过大挤死文字通道 | 补"垂直紧凑构图，避免横向撑满" |
   | 高潮场面平淡低幼 | 补"粗黑钢笔墨线、浓重纯黑墨块、强动势"（见第四层墨重强化） |

## 七、明确不做的事

**不要把版式与文字交给生图模型。** 实测过让模型自己排分格、画黑框、把标题与文案写进画面：
中文渲染虽准，但产出必然滑向"漫画页"（分格框 + 旁白框），与本系列的"图文结合长图"是两种形态，
且文字变成不可编辑的像素、语义三色系统无法落实。

**分工固定为：模型只负责画插画（无文字、透明背景、开放式构图），版式与文字归排版引擎。**
