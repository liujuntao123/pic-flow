## 一、设计系统

在对 v1（漫画感强但版式趋同）、v2（杂志感强但留白过度、画面割裂）与
v3（尝试紧凑但偏模板化卡片）进行视觉复盘后，定稿确立了
**"战局全景连续漫画（Sequential Battle Manga）"**的核心定位。

### 1. 严格四色分层色彩规范

避免杂乱与大面积色块，全篇严格遵循极简高反差色彩规范：

- **基准线稿色**：`#222222`（主标题与正文高对比度）+ 纯白背景 `#FFFFFF`
  （保证黑白钢笔漫画线条的纯粹性）。
- **橙色动作/强调（`#E8842B` / `#F6A83C`）**：战术动作、盟誓、关键谋略高亮、
  主角主动性发言气泡。
- **蓝色策略/对话（`#236EA8`）**：人物客观分析、引言、冷峻决策对话框、时间地标。
- **红色危机/战局高潮（`#D4483B`）**：敌军南下、兵力对比、战舰起火、转折节点、
  历史定论警示。

配色、字体映射与生图画风后缀统一定义在项目根目录 `style.json`（由迭代期的
`chibi-v4` 风格包定稿而来，`name` 现为 `chibi`），并内嵌于各
`layout/blockN.json` 的 `theme` 字段。

### 2. 动线与视觉层级

- **告别千篇一律的卡片化**：摒弃连续圆角大卡片，采用**无框出血、场景贯穿、
  前后叠压**的漫画分镜手法。
- **气泡与人物呼应**：气泡支持指向尾巴（`bl/bc/br/tl/tc/tr` 上下向，
  `lc/rc` 左右横向），气泡与人物头部叠压 20~60px，让对白真正从人物口中吐出。
- **章节叙事连贯推进**：在每个 block 底部增加统一的章节推进指引箭头
  （如 `战局推进 · 第二幕：孙刘联盟破冰对峙 →`），读者下滑阅读时获得
  连续翻页般的连贯感。

## 三、落地文件清单

1. **引擎增强（已回流 skill）**：
   - `scripts/compose.py`：`paint_box()` 新增气泡左右侧边尾巴 `tail: "lc"` /
     `"rc"`（横向指针），使横向分栏布局中的气泡能精准指向左右两侧人物；
     同时补齐了 `tc` 分支（原实现会把未知 tail 值静默降级为 `tl`）。
   - 该增强已合并进 `~/.dsh/skills/pic-flow/pipeline/compose.py`，本目录
     `scripts/` 与 skill 逐字节同步。
2. **风格包**：`style.json`（配色 / 气泡默认参数 / 文楷·快乐体·马善政毛笔字体系 /
   生图画风后缀）。
3. **分块排版**：`layout/block1.json` ~ `layout/block8.json`。
4. **渲染产物**：`blocks/final1.png` ~ `blocks/final8.png`；
   `output/赤壁之战_长图.jpg`（1080 × 12970）+ `_preview.jpg`（550px 宽）。
   （`stage*` 调试画布与 `debug*` 网格稿为过程稿，已清除。）

## 四、验证与质检结果

1. **静态机检**：`scripts/layout_lint.py` 逐块检查
   `layout/block1.json` ~ `block8.json`，全部 `OK, hard=0, warnings=0`
   ——零越界、零文字重叠碰撞、无过度居中警告。
2. **视觉走查**：逐块经识图复核并修复了首轮渲染中的问题：
   - Block 1 曹操与左侧文案的间距及折行；
   - Block 3 孙刘对峙时气泡尾巴指向及中轴徽章位置；
   - Block 4 连环计三钉的纵向间距，彻底分离蒋干与下层战船的图文层次；
   - Block 5 苦肉计说明文字与爆炸气泡、战火船头的重叠微调；
   - Block 6 华容道关羽与曹操的对白气泡贴合、路线轴文字避让；
   - Block 8 周瑜头顶气泡与右侧金句框的纵向对齐。
3. **可复现性**：用本目录 `scripts/` 重跑排版与拼接，8 个 block 与成品长图
   均与 `blocks/`、`output/` 现存文件 md5 一致——源文件可完全再生成品。
4. **整图拼接**：`scripts/stitch.py` 无缝拼接，总分辨率 1080 × 12970 像素，
   画质清晰、色调统一、节奏跌宕起伏。
