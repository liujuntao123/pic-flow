## 核心论证与技术亮点

1. **科普论证递进链条（7 Block 完整闭环）**：
   - `hook`（迷信之惑与历史设问）：拒绝廉价的现代傲慢，提出真正核心问题——实验真实，但理论框架错误。
   - `context`（假求外物：草木皆腐与金石不朽）：葛洪《抱朴子》哲学，草木焦烂无法自全，唯有摄入“百炼不消”的真金方能分享不朽。
   - `buildup`（惊天化育：丹砂化汞的化学奇迹）：还原真实的 $HgS \leftrightarrow Hg$ 氧化还原反应与金汞齐现象，“变化而不亡”在古人眼中是不灭神迹。
   - `buildup`（明知有毒：以猛攻猛与微毒陷阱）：古人知毒而伏火；朱砂胃肠吸收率仅约 0.2%，真实的低急性毒性反而强化了长生信念。
   - `climax`（密闭宇宙：永不犯错的自洽逻辑闭环，**落在 71% 进度**）：丹炉模拟乾坤小宇宙，成则丹法神妙，败则火候未到，绝不推翻理论本身。
   - `meaning`（认知错觉：后见之明与集体大脑）：破除 Hindsight Bias，指出认知劳动分工（Epistemic Division of Labor）才是现代人领先的真正底座。
   - `ending`（科学真谛：承认错误的制度）：科学最伟大的进步在于把“承认自己可能会错”制度化，理性警句收束。
2. **去容器化画卷感**：
   - 彻底打破卡片框束缚，文字直排底色，快乐体/文楷/毛笔字自然分层。

## 实测状态（用机检链自行复现）

本工程是历史产物：**排版源码可复现**，但机检链会如实报出以下问题（不是机检误报）：

- `lint`（`checks/lint.mjs`）：7 个 block 全部 `hard=0`。
- `checks/geom.mjs`：若干 block 报「自动折行 / 孤字行」提示（文案与栏宽的历史遗留）。
- `checks/occlusion.mjs`：`block3` 报 1 处真实压盖（约 710px）；`checks/clearance.mjs` 另有若干气泡净空 <40px。
- 本目录没有 `fonts/` 软链，两个引擎都会回退到 skill 自带的 `fonts/`（这正是它声明的文楷/快乐体/毛笔三级字阶）。
- 因此成品图**不是**逐字节可复现：用当前引擎重渲，版式一致、字形栅格化有亚像素差异。

```bash
# 在 skill 根目录复现（<项目> 指向本目录）
node pipeline/canvas/checks/all.mjs <项目>/layout/block*.json
```
